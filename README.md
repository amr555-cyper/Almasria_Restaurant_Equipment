# تعديل الموقع
- كل البيانات (الأرقام، الروابط، الخريطة): `assets/js/config.js`
- المنتجات: أضفها في مصفوفة `PRODUCTS` بنفس الملف، وضع الصور في `images/`
- استبدل الصور بنفس الأسماء (أو غيّر المسار في config.js): `hero` و`about` وصور الأقسام
- الفورم: ضع رابط Formspree في `formEndpoint`، وبدونه يفتح واتساب برسالة جاهزة
- للنشر: ارفع المجلد كما هو (Netlify / GitHub Pages / استضافة عادية)
